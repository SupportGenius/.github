# SupportGenius/.github

The GitHub organisation profile for [SupportGenius](https://supportgeni.us).

- `profile/README.md`: the page shown at [github.com/SupportGenius](https://github.com/SupportGenius)
- `assets/org-banner.png`: its banner, a copy of `assets/readme-banner.png` from
  [`website`](https://github.com/SupportGenius/website), rendered there by
  `tools/render-og.sh`. Re-copy it when it changes.
- `assets/org-avatar.png`: the organisation avatar, from the same script. GitHub
  has no API for it; upload by hand at
  `github.com/organizations/SupportGenius/settings/profile`.

Same house rule as the site: nothing is described as working unless it ships.
